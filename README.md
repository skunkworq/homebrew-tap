# Homebrew Tap for CloudGuardian

This is the official Homebrew tap for the CloudGuardian CLI.

## Installation

```bash
brew tap skunkworq/tap
brew install cloudguard
```

Or install directly:

```bash
brew install skunkworq/tap/cloudguard
```

## Updating

```bash
brew update
brew upgrade cloudguard
```

## Uninstallation

```bash
brew uninstall cloudguard
brew untap skunkworq/tap
```

## Documentation

Visit [https://cloudguard.dev/docs](https://cloudguard.dev/docs) for full documentation.
