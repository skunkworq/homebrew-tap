# Skunkworq Homebrew Tap

Official Homebrew formulas for Skunkworq command-line tools.

## Installation

```bash
brew tap skunkworq/tap
brew install aegis
```

Or install directly:

```bash
brew install skunkworq/tap/aegis
```

CloudGuardian remains available as `cloudguard`:

```bash
brew install skunkworq/tap/cloudguard
```

## Updating

```bash
brew update
brew upgrade aegis cloudguard
```

## Uninstallation

```bash
brew uninstall aegis
brew untap skunkworq/tap
```
